# Uni Dashboard logo studies

Four original vector directions based on the project's daily student dashboard, Waterloo setting, and existing neutral palette. These are proposals; the app icons have not been changed.

- **Next U** — a U monogram with a detached, angled upper terminal, suggesting the next item in the day. Recommended for its simplicity and connection to the existing U icon.
- **Ring Route** — an open campus loop and focus point, referencing Waterloo's Ring Road.
- **Campus Goose** — a single silhouette with a transparent wing cutout, a Waterloo reference.
- **Daystack** — three horizontal layers forming a compact D, representing the app's connected sources.

Open preview.html for the comparison and download links, or overview.svg for the vector presentation. Each standalone SVG has a transparent background, a square 100-unit viewBox, and no font or external asset dependencies. The default files are charcoal; files ending in -white are for dark backgrounds. Change the root color attribute to recolour a mark. The overview uses live text with a system font fallback; the marks themselves are entirely vector geometry.

The comparison includes 16 and 24 px specimens. For a production favicon, Next U and Ring Route retain the clearest silhouettes; the goose wing and Daystack gaps are finer at 16 px. Preview PNGs are raster exports for review only.

Rebuild SVG assets with node docs/brand/minimalist-concepts/build.mjs.
